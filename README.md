## 关于“循环优惠”这件事，两种做法有什么不同

市面上家宽 VPS 的长期折扣大致两种形态。一种是输入式循环码，结账页贴一串字符，验证通过后每个周期都按折后价扣款，这类码通常有有效期，还可能排除部分套餐，用之前得先确认适用系列。另一种是 SixtyNet 这种，折扣直接做进计费周期，没有码可输，也没有过期问题，代价是必须一次性付满一年。

两种做法各有取舍。输入式循环码灵活，月付也能享受折扣，但要盯着活动截止日；年付折扣稳定，不用记任何代码，缺点是资金占用大、中途换商家沉没成本高。如果你本来就打算长期用一个固定节点，年付折扣的实际收益和循环码差不多；如果你还在比较不同地区的 IP 效果，月付加短周期试错更合理，等确定了再转年付。
